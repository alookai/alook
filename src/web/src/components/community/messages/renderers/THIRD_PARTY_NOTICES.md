# Message renderer trial dependencies

## Chatscope Chat UI Kit React2.1.1

Published package: @chatscope/chat-ui-kit-react2.1.1. Source: https://github.com/chatscope/chat-ui-kit-react. The adapter imports the published dist/es/Message entry. Its Message, Header, CustomContent and Footer own the visual cell; canonical Alook content and actions remain React slots. Token CSS in chatscope-message-cell.module.css is original Alook adaptation; no vendor document stylesheet is copied. The narrow declaration reuses the public Message type for that exact published entry.
