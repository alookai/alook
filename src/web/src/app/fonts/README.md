# Local web fonts

The WOFF2 files are the Latin subsets from Fontsource 5.3.0:

- `@fontsource-variable/dm-sans`
- `@fontsource/dm-mono`
- `@fontsource/instrument-serif`
- `@fontsource-variable/caveat`
- `@fontsource/vt323`
- `@fontsource-variable/literata`

`dm-sans-600.ttf` is the DM Sans 9pt SemiBold file used by the Open Graph image route. Each family is distributed under the SIL Open Font License 1.1; the corresponding license text is in `licenses/`.
