Rui develops FrameNest, a desktop video editor, on his Mac and uses a Windows PC for compatibility checks. An export bug means moving a change to Windows and carrying the result back. He wants to assign the work from his phone and let the two agents exchange the commit and test result.

Both computers have their development tools and repository access. Rui connects them to Alook: Patch runs Claude Code on the Mac, and Check runs Codex on Windows. He keeps both computers online and adds the bots to /desktop-app.

## Give each computer a role

Rui opens /desktop-app in Alook on his phone and posts:

> @Patch Fix the export error, push the branch, and mention Check with the commit. @Check When Patch mentions you, fetch that commit, run the export tests on Windows, and report the result.

Patch makes the change, mentions Check in the channel, and hands it the commit. Check fetches that commit on Windows, runs the tests, and posts the results and any relevant logs. Rui can check that both bots used the same revision before deciding what to do next.

## Connect your two computers

1. On the **Machines** page, connect both computers. Check that each agent can access the project and its test commands, that both clones use the same Git remote, and that the implementer can push to it.
2. In **My Bots**, create a bot for each machine and select its agent. Invite both bots to the same server and channel.
3. Mention both bots. Name the implementer and tester, and require a pushed branch and commit for the handoff. Ask the tester to report the tested revision and result in the channel.
