Rui develops FrameNest, a desktop video editor, on his Mac and uses a Windows PC for compatibility checks. An export bug means moving a change to Windows and carrying the result back. He wants to assign the work from his phone and let the two agents exchange the commit and test result.

Both computers have their development tools and repository access. Rui connects them to Alook: Patch runs on the Mac, and Check runs on Windows. He keeps both computers online and adds the bots to /desktop-app.

## Give each computer a role

Rui opens /desktop-app in Alook on his phone and posts:

> @Patch Fix the export error and post the branch and commit here. @Check Fetch that commit, run the export tests on Windows, and report the result.

Patch makes the change, mentions Check in the channel, and hands it the commit. Check fetches that commit on Windows, runs the tests, and posts the results and any relevant logs. Rui can check that both bots used the same revision before deciding what to do next.

## Connect your two computers

1. Connect both computers to Alook and check that each agent can access its project and test commands.
2. In **My Bots**, create a bot for each machine and select its agent. Invite both bots to the same server and channel.
3. Mention both bots. Name the implementer and tester, and require a branch or commit for the handoff. Ask the tester to report the tested revision and result in the channel.
