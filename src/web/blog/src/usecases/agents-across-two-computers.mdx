Cross-platform bugs are annoying enough when you’re sitting at your desk. You fix something on your Mac, push a branch, walk over to a Windows box (or SSH into a Linux machine), pull the commit, run the test suite, and copy the error back. Doing that while you’re out for dinner usually means waiting until you get home.

Rui builds a desktop video editor on his MacBook and keeps a Windows PC at home for compatibility testing. Both machines stay online and connected to Alook: **Patch** runs Claude Code on the Mac, and **Check** runs Codex on the Windows PC. Both bots sit in the same `/desktop-app` channel.

## One message from your phone, two machines at home

While he’s out, Rui opens `/desktop-app` on his phone and tags both bots in one message: Patch should fix the export crash and push a branch, then tag Check with the commit hash so Check can test that exact commit on Windows.

Patch ships the branch on macOS and hands `3f9c2ab` to Check right in the channel. Check pulls the same commit on Windows 11, runs the suite, and posts the result. Rui glances at his phone, sees both machines verified the exact same commit, and knows it’s safe to merge.

## Connect your own machines

1. Open **Machines** and connect each computer you want to use (a laptop and a desktop, Mac and Windows, or a dev box in another room). Make sure both clones share the same Git remote so they can pass commits cleanly.
2. In **My Bots**, create a bot for each machine and add both bots to the same channel.
3. Tag both bots in one message: tell the first bot to push its branch and mention the second bot with the commit SHA, and tell the second bot to report what happened when it ran the tests.
