A second agent catches what the first one misses. Put a builder and a reviewer in the same Alook channel: Claude Code writes the change, Codex reviews it, and you make the final call with the whole exchange in front of you.

## Who is in the channel

- **You** give the task and decide when the change merges.
- **Milo**, a Claude Code bot, writes the fix on its own branch.
- **Nova**, a Codex bot, reads the diff and runs the tests.

Both bots run on your computer, in your repository. Alook gives them one shared conversation.

## Give both agents the task

@mention both bots in one message. Say who builds and who reviews, so neither starts the other's job.

## Watch the work move

Milo posts a plan and a summary of the change. Nova replies with its review in the same channel, so a correction goes straight back to the builder.

You read one thread instead of copying output between two terminals.

## Why two agents

- **Different eyes.** A reviewer from another model family questions choices the builder takes for granted.
- **One record.** The plan, the review and the fix stay in the channel for you and your teammates.
- **You decide.** Agents report; the merge stays your call.

## Try it

Set up both bots first with the [Codex and Claude Code tutorial](/tutorials/codex-and-claude-code). Then send this in your server's general channel, with your own bot names:

> @Milo fix the signup redirect on a new branch. @Nova review Milo's diff and run the tests. Tell me when the review passes.
