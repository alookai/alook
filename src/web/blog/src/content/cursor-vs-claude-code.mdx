### Why use Claude Code if Cursor has Claude?

The same Claude model runs through different tools in Cursor and Claude Code. A Claude Code session has its own conversation, tools, and permissions, even when we open it inside Cursor. Billing differs too: new Cursor plans charge separately for Claude usage, while Claude Pro, Max, and Ultra include Claude Code within the plan's usage limits.

## If You Don't Write Code

### What should your first project be?

If you already have a page or project, change one small thing you can check. If you're starting from nothing, we'd make a personal page with one working button.

### How do you get started?

Use the same first task in either tool: a local page with one About button, without a login or external services.

#### In Cursor

1. Install Cursor and sign in. On your computer, create an empty folder called `my-first-page`, then [open that folder in Cursor](https://cursor.com/docs/get-started/quickstart). You don't need an existing repository.
2. Open Agent with `Cmd+I` on Mac or `Ctrl+I` on Windows. Ask: “Create a personal page in index.html, with the CSS and JavaScript in that file. Add an About button that shows a short bio when clicked. Keep it local, with no login, database, or external services.”
3. When Agent finishes, find `index.html` in that folder and open it in your web browser. You should see the page. If it doesn't open, tell Agent what happened and ask for the exact next step.
4. Click About: the bio should appear. Reload the page and try again. Then ask Agent to change the button's text, refresh the browser, and check that the new label appears and the button still works.

For visual edits after the page works, ask Agent to set up a local preview and give you its address. Open that address in the browser inside Cursor's Agents Window, then click Annotate in the browser toolbar. Select an element, describe the change, and press Enter to send the note. Older versions show a pen icon labeled Design Mode instead.

#### In Claude Code's desktop app

1. Install the Claude desktop app and sign in with an account that has Claude Code access. Open **Code** near the top of the left sidebar. You don't need to install the CLI to use this tab.
2. In the row below the prompt box, open the first selector and choose the top option under Local. Open the folder selector beside it, choose **Open folder…**, and select the empty `my-first-page` folder on your computer.
3. Give Claude the same page request shown above. When it finishes, ask for the exact path to the generated `index.html` and open that file in your browser. Follow the same button and label checks in Cursor step 4 above. If the page does not open, describe the result to Claude and ask for the exact next step.

We'd get that preview working before trying to publish. The agent may still need you to create a hosting account, connect a service, or add an API key. Ask it to explain each step before you approve it.

### Who checks the work?

Most people on one marketing team weren't technical. They [used Cursor's cloud agents in the web app](https://news.ycombinator.com/item?id=48028151) to change the website, blog, and landing pages. The agents opened GitHub pull requests, and engineers checked them before merging.

If you're working without an engineer, try every action in your first project before publishing. In April 2025, [a builder using Cursor](https://thomasbrouwer.substack.com/p/building-with-ai-2-trash-tv-aggregator-e55) found that a cookie banner appeared on the page but its Decline action hadn't been implemented. Click the buttons and check what happens before calling the feature done.

## How Do We Edit and Review Changes?

### While editing the code

With Claude Code's extension, you can point to a file and inspect its changes beside the code. Try the extension before switching editors just to get an agent.

**For UI tweaks and wording changes, we keep the file open and fix the details ourselves.** For a larger change across files, we let Cursor Agent take the first pass, then read the diff.

### Before the agent changes your files

On an unfamiliar project, check what the agent can change without asking. By default, Cursor asks before running terminal commands but can edit ordinary workspace files without asking. Configuration files need approval. To have Claude Code ask before file edits and commands that need permission, choose Manual. In its desktop Code tab, use the mode selector in the row below the prompt box. In the editor extension, click the mode indicator at the bottom of the prompt box.

## Which One Writes Better Code?

The two comparisons we found don't give us a quality reason to switch tools. In one small test with the same Claude model, both tools passed all 186 checks. In a separate bug-fix benchmark, both passed 20 of 27 tasks with the same model and effort setting.[^1][^2]

### What are you paying for?

**If Claude is what you're paying for, start with Claude Pro: Cursor charges extra for it.**

- Claude chat and Claude Code share your plan's usage limits. A busy day in chat can leave less for coding.
- Cursor's included usage pool is shared with the Grok apps. Requests in Grok chat draw from that same pool, leaving less for Cursor.
- Legacy Cursor Pro ($20/month) includes a monthly third-party model pool. Check your plan before using someone else's bill to estimate yours.

### What happens when you hit a limit?

When Claude Code stops for a limit, check `/usage` for the reset time first. Pro and Max have five-hour and weekly limits. Verified Ultra accounts have no five-hour limit, but weekly limits still apply.

If the reset's only a few hours off, we just wait. On a Claude subscription, an open interactive session can wait out a reset and resume. Sometimes it will ask you to confirm before carrying on. If the deadline can't wait, compare an upgrade with paid usage credit.

Cursor resets its included usage pool each week. Once you've used it up, you can wait for the reset or pay from prepaid credit. Auto Top-up buys more credit when the balance falls below your chosen threshold. A separate monthly additional usage limit caps how much paid usage you can consume, even if credit remains. Check both settings before paying to continue.

## Which Should You Try First?

Start with one small project in the tool you chose. Review what changed and try the result yourself, then check how much correction it needed and how much allowance the task used. Add the second tool when it has a defined job worth the extra setup or subscription, such as independently reviewing the same patch.

## Using Claude Code and Cursor Together

You can keep one editor, give the tools separate tasks, or bring their bots into a shared discussion.

### Keep Cursor and add a Claude Code session

The Claude Code extension runs its own session inside Cursor. It does not turn Cursor Agent into Claude Code or copy the other conversation's context.

1. Open your project in Cursor. On the Claude Code extension page, choose ["Install for Cursor"](https://code.claude.com/docs/en/vs-code#install-the-extension), then sign in to Claude. You'll need Pro, Max, or Ultra, or a Console account with separate billing.
2. If you prefer the CLI, install it and run `claude` from your project folder in Cursor's terminal.
3. Use `AGENTS.md` for shared project instructions. Direct loading needs Claude Code v2.1.277 or later and depends on the Project instructions setting. By default, a `CLAUDE.md` or `CLAUDE.local.md` in your project or a parent directory takes precedence. On a current version, use `/memory` to check what loaded. If `AGENTS.md` did not load, add `@AGENTS.md` to a `CLAUDE.md` beside it.

Claude Code's `/init` reads old Cursor rule files and adds the relevant instructions to its generated `CLAUDE.md`. If you change the Cursor rules later, you'll need to copy them over again.

### Give each tool a defined task

We keep Cursor for edits we expect to revise by hand several times. We hand Claude Code a bug to investigate or a separate change to implement. Review or commit the current edits before a handoff, so you can trace which tool changed what. A short status note and the relevant [session record](/blog/share-claude-code-session) give the next tool a starting point.

![Suggested workflow: use Cursor for hands-on editing or Claude Code for a defined task, then review the diff and tests yourself. Share rules and include a progress note at the handoff.](/blog/cursor-vs-claude-code/workflow.png)

Both tools offer cloud agents for work that needs to continue after you close your laptop. In Cursor's new plans, cloud agents start at Premium. With Claude, cloud sessions are available on Pro, Max, and Ultra.

When we want both agents and the people reviewing their work to discuss a result together, we use Alook. In this [multi-agent collaboration](https://alook.ai) workspace, Claude Code and Cursor connect as bot accounts that can reply to you and each other.
