## Review a launch announcement with your team’s existing AI agents

A marketing colleague has a launch announcement to finish. Their writing bot has prepared the draft, and an engineer's Codex already works with the product repository.

The marketing colleague posts the announcement in their shared Alook channel. The engineer asks Codex to check its feature claims against the code changes and PR status.

One sentence says a new feature is available. Codex finds the implementation, but its PR is still open. The code exists. The change hasn't been merged. Codex posts the PR beside the draft and flags the availability claim.

The marketing colleague asks Codex whether that sentence needs to come out entirely or can describe something already released. After checking the answer with the engineer, they remove the promise and ask the writing bot to revise the surrounding paragraph.

**The announcement no longer promises a feature that hasn't shipped.** The marketing colleague has the evidence behind that change, and the engineer has checked the wording. The team can finish the announcement without treating unfinished code as a release.

## Can Grok Bot run locally?

For a local model, the first choice is which agent and model provider to run. Changing the chat space won't turn hosted inference into local inference. The word “local” on its own doesn't tell you enough.

### Run Grok Bot commands on your local computer

Grok Bot can [run commands on your computer](https://docs.x.ai/grok-bot/computer-and-apps#your-local-computer-is-separate) once local execution is enabled, with per-command approval as the default. It can work with local files. Reading a repository doesn't require a move to Alook.

### Can you self-host Grok Bot?

Running the whole product yourself is different. Grok Bot uses [Cursor-hosted computers](https://docs.x.ai/grok-bot/security); on-premises and bring-your-own-image deployment aren't supported. It also has no customer-facing model picker.

### Local AI agents and local models in Alook

Alook lets you keep the agent software you've set up beside your project. The model it calls still depends on that agent's configuration: a locally running agent can use a hosted model. Our [local AI agents guide](/blog/local-ai-agents) goes into the different setups.

## Grok Bot Shared Bots and Alook group conversations

Grok Bot's [Shared Bots](https://docs.x.ai/grok-bot/shared-bots) let Cursor teammates use the same Bot in group chats while keeping each person's private chat private. Shared Bots run in the cloud.

Alook keeps [each owner's bot in the discussion](/blog/introducing-alook). The marketing colleague keeps their writing bot, the engineer keeps their coding bot, and teammates address either one directly in the project channel. A colleague questions the agent that supplied a finding, with its owner there to help explain it.

While updating one of our comparison articles, we found tool names broken into fragments in the mobile tables. One bot had prepared the copy; another caught the layout problem in the mobile view. The fix was to give the tables room to scroll. We kept the problem, the correction, and the final check in the article's discussion.

That's why we care about keeping the people and bots doing the work in the conversation. A finding needs somewhere to go, and someone needs to act on it.

Alook lets the team keep its tools and project knowledge with the colleagues who already use them. When you need another bot for the work, an existing bot can request one for you to approve.

## Keep working with your laptop closed: Grok Bot vs Alook

A provided computer is a real advantage if you don't want to keep one running yourself. You can close your laptop and leave Grok Bot's cloud work going. For a team already using its mobile app and Slack connection, that's a good reason to stay.

With Alook, the computer running a bot needs to stay online. You could leave a separate machine running and check its work from your phone. Put that bot on the laptop you carry around, though, and it stops executing when the laptop sleeps.
